# Beginner Python Learning Path

This short path introduces the foundations needed before studying the advanced concepts in this repository. Follow the subjects in order and practice each one with small programs.

## 1. Python Fundamentals

Learn how to run Python programs and work with variables, comments, basic operators, strings, numbers, booleans, and `None`.

**Practice:** Build a temperature converter and a simple calculator.

## 2. Control Flow

Learn how to make decisions and repeat work using `if`/`elif`/`else`, `for` loops, `while` loops, `break`, and `continue`.

**Practice:** Create a number-guessing game.

## 3. Collections and Comprehensions

Learn how to store and organize data with lists, tuples, dictionaries, and sets. Then practice concise list and dictionary comprehensions.

**Practice:** Count word frequencies in a sentence and remove duplicate values.

**Related example:** [`32.advanced_list_comprehension.py`](../32.advanced_list_comprehension.py)

## 4. Functions and Error Handling

Learn how to define and call functions, use parameters and return values, understand local and global scope, and handle expected problems with `try`/`except`.

**Practice:** Write reusable functions for validating and processing user input.

## 5. Object-Oriented Programming

Learn how to create classes and objects, define methods, use constructors, and understand encapsulation, inheritance, and polymorphism.

**Practice:** Model a small library system with `Book`, `Member`, and `Library` classes.

**Related examples:**

- [`15.encapsulation.py`](../15.encapsulation.py)
- [`18.inheritance.py`](../18.inheritance.py)
- [`19.polymorphism.py`](../19.polymorphism.py)

After these five subjects, continue with iterators, generators, decorators, context managers, and concurrency.
